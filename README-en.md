# Discord Bot Mon Bureau Numérique

[🇫🇷🇨🇦](README-en.md)

**⚠️ Abandoned project, API doesn't work anymore and I don't really have time, motivation or need to port the bot to use
the new Skolengo API. This repository has been archived.**

This bot is a Discord bot that allows interacting with Mon Bureau Numérique data.

We can:
 - Read our mails
 - See our homeworks
 - See our timetable
 - See our grades

It logs in to Mon Bureau Numérique using phone API. It mimics a phone to logs in and access data.

For a user to log in, it must give its username and temporary password generated by the Mon Bureau Numérique website
using `/se-connecter <username> <password>`. The bot logs in and stores the auth ticket given by the API in its database.
Credentials are not kept once logged.
